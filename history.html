Topic 1: Historical Development of HTML

Early Development

HTML was invented by Tim Berners-Lee in 1991 with 18 basic tags that focused heavily on simple text and hyperlinks within text. Early developers initially used complex layout tables to organize layouts, which proved resource-heavy and hard for modern screen processors to navigate cleanly.

Key Milestones & The HTML Living Standard

Modern layouts utilize dedicated processing infrastructures to read and handle site structural markups seamlessly across unique operational applications:

  • 1991 — First HTML Draft: Tim Berners-Lee publishes HTML Tags, introducing foundational elements such as headings, paragraphs, lists, and anchor links (<a>).
  • November 1995 — HTML 2.0: The Internet Engineering Task Force (IETF) publishes RFC 1866, establishing the first formal standard for HTML forms and core document structure.
  • January 1997 – December 1999 — HTML 3.2 & HTML 4.01: The World Wide Web Consortium (W3C) standardizes HTML 3.2 and HTML 4.01, introducing Cascading Style Sheets (CSS) support to separate visual styling from semantic markup.
  • 2004 — Formation of WHATWG: Engineers from Apple, Mozilla, and Opera form the Web Hypertext Application Technology Working Group (WHATWG) to evolve HTML incrementally while the W3C focuses on strict XML-based XHTML 2.0.
  • October 28, 2014 — W3C HTML5 Recommendation: W3C publishes HTML5 as a formal Recommendation, adding native multimedia (<video>, <audio>), graphics (<canvas>), and semantic landmarks (<header>, <nav>, <main>, <article>).
  • May 28, 2019 — Unified HTML Living Standard: W3C and WHATWG sign a Memorandum of Understanding retiring separate W3C HTML specifications. WHATWG's HTML Living Standard becomes the sole authoritative specification—updated continuously as browsers ship new features, permanently eliminating numbered versions (there is no "HTML6").

Recent Developments & Modern Layout Engines

Modern browsers implement the HTML Living Standard through dedicated rendering and layout engines that parse HTML into the Document Object Model (DOM) and combine it with CSS:

Browser Engine Primary Organizations Target Web Environments
Blink Engine Google Powers Chrome, Microsft Edge, and Opera platforms.
WebKit Engine Apple Powers Safari for iOS, iPadOS and macOS.
Gecko Engine Mozilla Independent, open-source engine that powers Firefox.
